# Board requirements and reproduction

The board gates are designed for ARM64 Debian systems with a Rockchip media
kernel. A usable board must provide:

- an SSH alias (default `t6`, override with `BOARD=<alias>`);
- 64-bit Debian with `git`, `cmake`, `make`, `cc`, Python 3 and FFmpeg;
- `/dev/mpp_service` and `/dev/dma_heap/system`;
- passwordless `sudo -n` for the gate harness;
- enough storage for `~/rk-mpp-oracles` plus `/tmp` stream/reference copies.

The supported lab aliases are examples, not requirements:

```bash
BOARD=t6 scripts/setup_board_refs.sh
BOARD=luck2 scripts/setup_board_refs.sh
BOARD=my-board scripts/setup_board_refs.sh --check
```

`scripts/setup_board_refs.sh` is the single entry point for the C MPP decoder
and encoder oracles, the ioctl tracer and the corpus. `--check` is read-only;
it reports missing prerequisites and exits non-zero without cloning, building
or copying anything. Override paths on unusual boards:

```bash
BOARD=my-board \
ORACLE_HOME='$HOME/rk-mpp-oracles' \
CORPUS='$HOME/rk-mpp-oracles/corpus' \
scripts/setup_board_refs.sh
```

`scripts/board_regress_all.sh` fails on unexpected `SKIP` lines by default.
Use `ALLOW_SKIPS=1` only when running on a board that intentionally lacks a
codec or hardware block. Individual benchmark/gate scripts still expose their
specific `MPP_REF`, `MPP_BIN`, `MPP_LIB` and corpus overrides.
